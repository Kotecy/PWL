# История версий

## 0.3.1

- Скругление верхних углов перенесено на само окно — больше нет видимого второго слоя за углами
- Убраны тяжёлые градиенты и широкие тени, из-за которых окно приветствия зависало при перетаскивании
- Версия возвращена под карточку приветствия
- Экраны переведены на обычный поток вместо абсолютного позиционирования

## 0.3.0

- Крупная миграция интерфейса с Tkinter Canvas на HTML/CSS/JavaScript
- Python сохранён как backend через JS API pywebview
- Окно осталось frameless: отображается только собственный бар PWL
- Сборка переведена на WebView2/pywebview
