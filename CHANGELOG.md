# История версий

## 0.7.1

### Новое
- В настройках появился выбор способа запуска клиента: «Классический (.bat)» или «Автоввод» (рекомендуется для старых клиентов)
- По умолчанию используется способ запуска «Классический (.bat)»

### Исправления
- Выбор Elementclient теперь открывает системный диалог и сохраняет полный путь — раньше путь не запоминался
- Контекстное меню аккаунта больше не закрывается сразу после открытия
- После сохранения пути изнутри сервера интерфейс больше не раздваивается (список серверов и таблица аккаунтов)
- Колонка «Сервер» в таблице аккаунтов всегда показывает имя текущего сервера
- Из окна выбора Elementclient убран лейбл «PWL»

## 0.7.0

### Реальный функционал
- Серверы и аккаунты хранятся в `%APPDATA%\PWL\config.json` и загружаются при старте (убран MOCK_ACCOUNTS)
- Добавление/редактирование/удаление аккаунтов через контекстное меню (правый клик) — данные реально сохраняются
- Кнопка «Войти» запускает `elementclient.exe` из пути сервера и автоматически вводит логин/пароль через Win32 `SendInput` (работает с любыми клиентами, включая те, что не поддерживают xml/аргументы)
- Путь к Elementclient и создание серверов сохраняются через бэкенд

## 0.6.0

### Настройки
- В титульном баре рядом с переключателем темы добавлена шестерёнка «Настройки»
- Кнопка темы перемещена левее шестерёнки
- По клику на шестерёнку открывается модальное окно настроек по центру приложения
- Переключатель «Сворачивать в трей»: при включённой настройке кнопка «Свернуть» скрывает окно вместо сворачивания в панель задач; значение сохраняется в config.json
- Блок **WIP** заменён на благодарность игрокам Perfect World (сделано с любовью от Kotecy)
- Модалка закрывается кликом вне карточки или клавишей Esc

### Аккаунты
- В таблице аккаунтов отображаются иконки классов (web/class/*.webp): 18 иконок, включая Жнеца

## 0.5.2

### Аккаунты
- Перетаскивание персонажей в списке аккаунтов: строка следует за курсором, остальные плавно разъезжаются (FLIP-анимация), автопрокрутка у краёв таблицы
- Форма аккаунта полностью очищается при каждом открытии
- После добавления аккаунта возврат в таблицу текущего сервера, а не в список серверов
- Убрано поле «Сервер» из формы аккаунта (включая шаги мастера)

### Список серверов
- Пагинация: каждые 4 сервера на новой странице (кнопки 1, 2, 3…), при добавлении сервера переход на его страницу
- Разнообразие эмблем: 7 вариантов глифов, перемешиваются случайно при каждой отрисовке
- У сервера без пути до Elementclient рядом с названием красный крестик; по правому клику — контекстное меню «Добавить путь Elementclient»
- Модальное окно выбора пути открывается и при попытке войти на сервер без клиента
- Убран заголовок «Серверы» — осталась только кнопка добавления

### Визуал
- Карточки серверов переработаны: круглая эмблема с орбом, кольцами, статус-индикатором «в сети», светящаяся кромка и ореол в палитре сервера
- Крестик-предупреждение: симметричный, по центру круга
- Таблица аккаунтов больше не растягивается на всё окно: шапка и кнопки прилегают к таблице, внутренний скролл с липкой шапкой

### Прочее
- Исправлен сценарий «Принять» в форме аккаунта: возврат работал только со второго нажатия
- Добавлен cache-busting (?v=) для CSS/JS в WebView

## 0.4.0

- Из приветственного окна убран подзаголовок, переход ведёт сразу к добавлению сервера
