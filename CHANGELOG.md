# История версий

## 0.3.0

- Крупная миграция интерфейса с Tkinter Canvas на HTML/CSS/JavaScript
- Python сохранён как backend через JS API pywebview
- Окно осталось frameless: отображается только собственный бар PWL
- Добавлены чёткие SVG-иконки, плавные hover/click-состояния и настоящие CSS-тени
- Сохранены темы, приветствие, подтверждение и номер версии
- Сборка переведена на WebView2/pywebview

## 0.2.3

- Восстановлена оконная основа версии 0.1.0

## 0.2.2

- Тёмная тема стала светлее и серее
