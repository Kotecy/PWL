# История версий

Патч (0.2.1) — мелкие правки и фиксы. Минор (0.3.0) — крупные изменения.
Текущая версия видна в верхнем баре и под карточкой приветствия.

## 0.2.1

- Исправлено смазывание окна при перетаскивании: перемещение отдано Windows
- Пересчёт скругления углов теперь только при реальном изменении размера
- Версия вернулась под карточку приветствия и появилась на экране серверов

## 0.2.0

- Клик по иконке в панели задач сворачивает и разворачивает окно
- Верхний бар 26 → 22 px, версия выводится рядом с названием
- Горячие клавиши не зависят от раскладки (работают на кириллице)
- Убран хоткей смены темы

## 0.1.0

- Окно без системной рамки со скруглёнными верхними углами
- Карточка приветствия с рабочей кнопкой «Принять»
- Светлая и тёмная темы с переключателем солнце/луна
- Сборка PWL.exe через GitHub Actions
