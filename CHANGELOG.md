# История версий

## 1.0.0

Приложение переписано с нуля: вместо Python + pywebview — **Rust + Tauri 2**. Подробный разбор
узких мест старой версии и замеры — в [AUDIT.md](AUDIT.md).

### Новое
- Нативное приложение на Rust и Tauri 2 (WebView2), установщик NSIS без прав администратора
- Пароли на Windows защищены системой (DPAPI) и больше не лежат в JSON открытым текстом
- Аккаунты и серверы получили стабильные идентификаторы: перетаскивание строк больше не может привести к редактированию или удалению не того аккаунта
- Виртуальный список аккаунтов: в DOM только видимые строки, плавно на сотнях записей
- Поиск по серверам и аккаунтам, горячие клавиши: `Ctrl+N`, `Ctrl+F`, `Ctrl+T`, стрелки, `PageUp`/`PageDown`, `Home`/`End`, `Enter`, `Delete`, `Esc`
- Смена темы с анимацией: новая тема раскрывается кругом из кнопки (при включённом «уменьшении движения» в Windows — без анимации)
- Папка данных в настройках кликабельна: открывается в проводнике
- Настройка «Подтверждать удаление» и индикатор сохранения в статусбаре
- Автоматический перенос библиотеки версии 0.9.x из `%APPDATA%\PWL`; старые файлы не изменяются, можно вернуться на прежнюю версию
- Ошибка запуска игры (нет клиента, не найден `elementclient.exe`, отказ системы) показывается в интерфейсе

### Изменения
- Запуск игры — один процесс с готовым списком аргументов: без временного `.bat`, без `cmd.exe` и смены кодовой страницы; пробелы в логине, пароле и нике больше не ломают командную строку
- Данные хранятся в памяти, на диск пишутся отложенно и атомарно (временный файл → замена + резервная копия `.bak`) — обрыв питания в момент записи больше не уничтожает библиотеку
- Битый файл библиотеки и отсутствующий файл различаются: при повреждении данные восстанавливаются из копии, а не молча заменяются пустой библиотекой
- Иконки классов — два спрайта (тёмная и светлая тема) вместо 36 файлов, 232 КБ → 37 КБ; смена темы — смена CSS-переменной без перерисовки списка
- Все эмблемы серверов нарисованы заново: 20 иконок в духе Perfect World (облако сянъюнь, лотос, пагода, тайцзи, бацзы, нефритовая подвеска, веер, персик, тыква-горлянка, колокол, карп кои, перо феникса, фонарь, горы и волны, лапа тигра, волны, слиток, талисман, летающий меч, созвездие). Эмблема определяется идентификатором сервера и больше не меняется при каждой перерисовке
- В списке аккаунтов у класса только иконка (название — во всплывающей подсказке)
- Перерисованы значки темы и настроек
- Полностью переработан дизайн интерфейса, один SVG-спрайт для иконок
- Строгий CSP: без inline-скриптов и inline-стилей, без внешних ресурсов
- Нет Python, pystray и Pillow; трей встроен в Tauri

### Исправления
- Ник, логин и комментарий с символами `<`, `&` или разметкой больше не ломают вёрстку и не исполняются как HTML (в 0.9.x это была уязвимость в интерфейсе приложения)
- «Удалить сервер, но оставить аккаунты» теперь действительно сохраняет аккаунты: они переносятся на сервер «<имя> — аккаунты» (раньше уходили в недоступный `kept_accounts`)
- Временные `pwl_launch_*.bat` с паролем в открытом виде больше не создаются и не копятся в `%TEMP%`
- Удалён нерабочий способ запуска «Авто ввод» вместе с настройкой

## 0.9.0

### Новое
- Сервер можно удалить из контекстного меню (правый клик по карточке); если у сервера есть аккаунты, приложение спрашивает подтверждение — «Да» удаляет сервер вместе с аккаунтами, «Нет» удаляет только сервер, а аккаунты сохраняются
- В светлой теме используются отдельные иконки классов, чтобы они читались на светлом фоне
- В трее отображается иконка приложения вместо заглушки
- Окно открывается сразу с готовым интерфейсом: больше не мелькает пустое приветственное окно при запуске

### Изменения
- Способ запуска «Авто ввод» временно отключён в настройках — доступен только «Классический»

## 0.8.0

### Новое
- В настройках появился выбор способа запуска клиента: «Классический» или «Авто ввод» (подходит для старых клиентов)
- По умолчанию используется способ запуска «Классический»

### Исправления
- На втором шаге мастера аккаунт больше не теряется, а создаётся у только что добавленного сервера
- Выбор Elementclient открывает системный диалог в нужной папке и сохраняет полный путь
- Контекстное меню аккаунта больше не закрывается сразу после открытия
- После сохранения пути изнутри сервера интерфейс больше не раздваивается
- Колонка «Сервер» в таблице аккаунтов всегда показывает имя текущего сервера

## 0.7.0

### Реальный функционал
- Серверы и аккаунты сохраняются и загружаются при старте
- Добавление, редактирование и удаление аккаунтов через контекстное меню
- Кнопка «Войти» запускает `elementclient.exe` из пути сервера и автоматически вводит логин и пароль
- Путь к Elementclient и создание серверов сохраняются через бэкенд

## 0.5.2

- Модальное окно выбора пути открывается и при попытке войти на сервер без клиента

### Визуал

- Таблица аккаунтов больше не растягивается на всё окно: шапка и кнопки прилегают к таблице
